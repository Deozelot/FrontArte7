# Design Eval Rubric (score each 1–10; weighted total, pass ≥ 7.5)

### Design Quality (weight: 0.35)
Coherent visual system: typography scale and pairing, colour, spacing rhythm, hierarchy, composition. Does every page feel like the same considered product? Would this win a design award?

### Originality (weight: 0.30)
A clear, memorable concept that is NOT AI slop: no default purple gradients, no generic card grids with rounded corners and drop shadows, no stock SaaS layout. Reward creative leaps — unusual layouts, custom animation, distinctive colour work — that serve the cinema theme.

### Craft (weight: 0.25)
Detail work: alignment, consistent radii/borders, hover/focus states, transitions, loading/empty/error states designed (not plain text), mobile at 375px with no horizontal scroll, contrast, reduced-motion respected, no console errors, no layout shift.

### Functionality (weight: 0.10)
All routes in spec.md render real API data; forms submit; edit/delete work; navigation works.

Weighted = 0.35·D + 0.30·O + 0.25·C + 0.10·F
Scoring anchors: 5 = competent tutorial project, 7 = good professional site, 8.5 = portfolio/award-shortlist quality, 10 = Awwwards SOTD.
